PRIMEIRO PASSO

Conecte sua conta do GitHub

Para listar e excluir repositórios, autorize o GitHub CLI com sua conta.

O terminal executará estes comandos:

gh auth login --web --hostname github.com --git-protocol https gh auth refresh -h github.com -s delete_repo

O segundo comando concede a permissão necessária para exclusão. Siga as instruções exibidas no terminal.
